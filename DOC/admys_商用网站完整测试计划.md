## 1  测试目的与结论边界

### 1.1  测试目的

本计划用于补齐商用网站上线前尚未系统执行的测试，重点回答：

1. 核心业务是否可用、是否符合预期；
2. 游客 / 会员 / 管理员权限是否正确隔离；
3. 主流浏览器、手机端、微信内置浏览器是否可正常使用；
4. 业务接口在合理负载下是否稳定；
5. 安全整改是否仍有效，是否有新的回归；
6. SEO、可访问性、备份恢复、监控告警、合规材料是否达到商用最低标准。

### 1.2  与已完成测试的关系

| 已完成 | 本计划需要补做 |
| ------ | -------------- |
| 外部黑盒安全回归 | 完整功能与端到端业务流程 |
| Tor / 直连压力抽样 | 业务端点阶梯压测与稳态压测 |
| 响应头与限流抽样 | 权限矩阵、越权、禁用账号、Token 失效 |
| 无 | 浏览器 / 移动端 / 微信内置浏览器 |
| 无 | Lighthouse、SEO、无障碍 |
| 无 | 备份恢复、监控告警、ICP/隐私合规检查 |

### 1.3  结果填写约定

每个用例统一使用以下状态：

| 状态 | 含义 |
| ------ | ------ |
| 未测 | 尚未执行 |
| 通过 | 实际结果符合预期 |
| 失败 | 不符合预期，需记录缺陷编号 |
| 阻塞 | 环境或前置条件不可用，暂时无法测 |
| 不适用 | 当前版本无该功能或业务明确不要求 |

缺陷建议编号格式：`BUG-YYYYMMDD-序号`，例如 `BUG-20260719-01`。

## 4  执行优先级与上线放行门禁

### 4.1  优先级

| 优先级 | 范围 | 建议顺序 |
| ------ | ------ | -------- |
| P0 | 注册登录、联系表单、管理员登录、权限隔离、生产冒烟 | 第 1 天必须完成 |
| P1 | 通知推送、用户管理、评价、移动端核心页、安全回归 | 第 2 天 |
| P2 | 浏览器兼容、Lighthouse、SEO、无障碍、业务压测 | 第 3 天 |
| P3 | 备份恢复、监控告警、合规材料、稳态压测 | 上线前一周内完成 |

### 4.2  商用上线放行标准

全部满足才可判定「具备商用上线条件」：

1. 所有 **P0** 用例通过，无未关闭致命缺陷；
2. 所有 **P1** 用例通过，或仅剩已评估可接受的低风险遗留项；
3. 生产冒烟通过，且无真实用户数据外泄；
4. 权限矩阵无越权；
5. 联系表单、登录、注册限流与 Turnstile 仍生效；
6. 移动端首页 / 会员 / 联系 / 后台无明显遮挡、不可点、文字溢出；
7. Lighthouse 性能 / SEO / 可访问性达到团队阈值，或缺陷已评估；
8. 数据库备份与恢复演练至少成功 1 次；
9. 服务存活监控与错误告警可用；
10. ICP、隐私政策、用户协议等合规项完成或有明确豁免说明。

1. 只在**预发 / 隔离环境**压测，不对生产做破坏性压测；

3. 每个场景固定：目标 URL、方法、请求体、超时、持续时间、阶梯；

## 12  已知风险与测试时特别关注点

以下来自当前代码审阅，执行时请重点核实，不要默认已修复：

| 风险编号 | 级别 | 现象 | 建议验证 |
| -------- | ------ | ------ | -------- |
| RISK-01 | 高 | 注册接口当前未见 Turnstile 强制校验 | 确认是否可脚本批量注册；上线前评估是否必须补齐 |
| RISK-02 | 中 | 会员页姓名/邮箱/手机 maxLength 大于后端限制 | 用边界值打出前后端不一致缺陷 |
| RISK-03 | 中 | 评价内容前端要求 ≥10 字，后端只校验非空 | API 直提短内容验证 |
| RISK-04 | 中 | `/auth/me`、通知、评价接口无限流 | 压测与滥用场景记录 |
| RISK-05 | 低 | 后台 Layout 只检查 `admin_token` 是否存在 | 用会员 token 写入该键验证是否被 API 拒绝并回登录 |
| RISK-06 | 低 | Contact 页仍展示电话/邮箱，页脚已删除 | 与产品确认最终展示策略 |
| RISK-07 | 低 | 注册 `promoCode` 不校验有效性；会员页优惠券为硬编码 | 确认业务规则，避免用户误解「券已生效」 |
| RISK-08 | 信息 | 外部扫描到的 `/api/health` 等路径并非本仓库正式接口 | 不要当功能验收，只做拒绝访问验证 |
| RISK-09 | 高 | `sql/init.sql` 未创建 `reviews` 表，但代码会读写评价 | 干净环境执行 F-068；上线前必须补建表或迁移脚本 |
| RISK-10 | 中 | 通知 `PUT` 更新可能未复用创建时的长度上限 | 执行 F-130 |
| RISK-11 | 中 | 限流为单实例内存实现，多实例/重启后不共享 | 集群或滚动发布后复测 429 行为 |
| RISK-12 | 低 | JWT 存于 `localStorage`，依赖 CSP/XSS 防护 | 执行 S-007、S-014；退出后确认历史页不能复用敏感态 |
| RISK-13 | 信息 | CI 部署可能跳过后端测试且使用 `npm install` | 上线门禁应另有构建/测试通过证据，不只依赖自动部署成功 |
