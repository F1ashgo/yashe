## 1  执行摘要

本次只读巡检确认：**核心业务服务当前可用，未见持续 5xx 或服务宕机。**

主要发现分三类：

1. **正常**：`yashe-api`、Nginx、MySQL、Redis 均在运行；API 仅监听本机 `8080`；公网仅开放 `22/80/443`。

综合判断：**线上可用性良好，可继续功能测试；安全与运维加固建议在下周内完成。**

## 4  Nginx 访问与错误日志

### 4.1  状态码概况（access 当前日志 + 当日轮转日志）

| 状态码 | 次数（约） | 含义 |
| ------ | ---------- | ------ |
| 404 | 4466 | 大量扫描与不存在静态路径 |
| 401 | 540 | 未认证访问受保护 API（预期行为） |
| 400 | 56 | 非法/不完整请求 |
| 405 | 12 | 方法不允许 |
| 429 | 7 | 限流生效 |
| 403 | 4 | 规则拒绝（如 `/.env`） |
| 499 | 5 | 客户端主动断开 |
| 5xx | 0 | **未见服务端错误响应** |

### 4.2  高频 4xx 路径（节选）

| 次数 | 状态 | 路径 | 解释 |
| ------ | ------ | ------ | ------ |
| 406 | 401 | `/api/notifications/latest` | 未带 Token 访问通知接口，符合当前鉴权设计 |
| 97 | 404 | `/`（落到 API 主机默认站点） | 扫描或错误 Host 访问 |
| 30 | 404 | `/robots.txt` | 爬虫/扫描 |
| 28 | 404 | `/sitemap.xml` | 爬虫/扫描 |
| 28 | 404 | `/favicon.ico` | API 主机无该静态资源 |
| 14+ | 404 | `/.env`、`/.git/config` 等 | 凭据扫描，未命中真实文件 |
| 11 | 400 | `/api/auth/login` | 请求体/字段校验失败 |

### 4.3  error.log 要点

1. 大量 `open() "... failed (2: No such file or directory)"`  
   目标多为 `env.js`、`swagger.json`、`/.env`、`robots.txt` 等，属于扫描噪音。
2. 出现 `access forbidden by rule` 拦截 `/.env`、`/.git-credentials` 等，说明 Nginx 规则有效。
3. 2026-07-19 14:22 有 Nginx reload / 平滑重启记录，随后服务继续正常。
4. 有一条登录相关告警：`client request body is buffered to a temporary file`（`POST /api/auth/login`），属请求体缓冲提示，不是业务故障。

## 6  安全态势

### 6.1  已确认的有效防护

1. API 仅本机监听，经 Nginx 反代对外。
2. Redis 仅本机监听。
3. 安全组挡住了 MySQL / 宝塔公网端口。
4. Nginx 对部分敏感路径返回 forbidden。
5. 未认证通知接口返回 401，不再公开数据。
6. 限流返回 429，具备基本防爆破能力。

### 6.2  风险与缺口

| 编号 | 级别 | 风险 | 建议 |
| ------ | ------ | ------ | ------ |
| OPS-01 | 中 | ~~`nginx.service` 未 enable~~ **已处理** | 2026-07-20 已 `systemctl enable nginx`，当前为 enabled + active |
| OPS-02 | 中 | MySQL 监听 `*:3306/33060` | 改为 `bind-address=127.0.0.1`，并复核安全组 |
| OPS-03 | 中 | 宝塔面板监听 `0.0.0.0:8888` | 仅本机/白名单，或关闭公网面板入口 |
| OPS-04 | 低 | 登录失败打印完整堆栈 | 改为 warn 单行日志，避免误判为故障 |
| OPS-05 | 低 | API 主机缺少 `robots.txt`/`favicon` | 可选；不影响业务，可减少无意义 404 |
| OPS-06 | 低 | SSH 扫描噪音持续 | 保持密钥登录；可考虑 fail2ban / 改端口 / 白名单 |
| OPS-07 | 信息 | `kdump` failed | 与业务无关，可按运维需要修复或忽略 |
