# 关于我们页 — 营业执照展示设计

日期：2026-07-20  
范围：`yashe/view` 关于我们页（`/about`）底部「荣誉与资质」区块

## 目标

在「荣誉与资质」区块中突出展示公司营业执照（广州雅舍室内设计有限公司），采用单独一行居中布局，并与现有证书灯箱交互保持一致。

## 背景

现有页面已有两张证书卡片（香港建造业议会奖项 / 注册专业行业承造商），使用 `CERTIFICATES` 数据 + `cert-grid` 双列布局 + 点击灯箱放大。营业执照为横版官方证件，不宜与竖版证书共用同一网格比例。

## 方案选择

采用**独立区块**方案：

1. 标题区下方先展示居中营业执照卡片
2. 其下保留原有两张证书的 `cert-grid`（布局与样式不变）

不采用：同一网格第三行跨列、或把执照放在证书下方。

### 区块顺序（`about-cert` 内）

2. 营业执照居中卡片（新增）
3. 原有两张证书网格（不变）

### 交互

- 点击执照图片打开现有 `cert-lightbox`
- Escape / 遮罩 / 关闭按钮均可关闭（沿用现有逻辑）
- 灯箱 caption 显示类型 + 标题

实现上可将执照与现有证书共用同一选中态结构（同一 lightbox 状态），执照单独渲染卡片 DOM，不必强行塞进 `CERTIFICATES` 双列 map。

## 样式与响应式

### 执照卡片

- 最大宽度约 `800px`，水平居中
- 图片区横版比例约 `16:10`，浅色底（与现有 `cert-card--light` 一致）
- 卡片视觉语言与现有 `cert-card` 对齐（边框、金线下划、hover 轻微上浮）
- 与下方证书网格间距约 `40–48px`

### 灯箱

- 横版图容器放宽至约 `min(1000px, 92vw)`，`object-fit: contain`，避免裁切

### 移动端（≤768px）

- 执照卡片全宽
- 图片区按横版比例自适应
- 「点击查看大图」提示常显（与现有证书一致）

## 非目标

- 不新增独立「荣誉与资质」路由页
- 不替换或删除现有两张香港资质证书
- 不改动站点导航 / Footer / 后端 API
- 不做 OCR 或信用代码在线核验

## 验收标准

1. `/about` 底部「荣誉与资质」中，营业执照单独居中展示在两张证书之上
2. 图片可正确加载，横版内容完整可见（卡片与灯箱均不裁切关键信息）
3. 点击可放大；Escape / 遮罩 / 关闭按钮可关闭
4. 桌面与移动端布局正常，原有两张证书展示与交互不受影响
